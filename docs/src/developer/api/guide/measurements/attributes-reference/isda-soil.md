# iSDA Soil

Static soil and terrain properties. Soil attributes use the depths indicated in their names; slope has no soil depth. Texture class is categorical.

## `isda_soil`

Catalogue label: **iSDA Soil**.

| API attribute | Name / meaning | Output unit | Ensemble field |
|---|---|---|---|
| `ph_0_20` | pH at 0-20 cm depths | pH | No |
| `clay_0_20` | Clay content (mean) at 0-20 cm depths | % | No |
| `sand_0_20` | Sand content (mean) at 0-20 cm depths | % | No |
| `slope` | Slope | % | No |
| `texture_class` | Soil texture class at 0-20 cm depths | code | No |
