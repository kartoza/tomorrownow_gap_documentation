# TAHMO weather stations

Quality-controlled station data, catalogue labelled 2018–2025 v1. Rainfall estimates and quality flags are separate fields; retain the flags when interpreting gap-filled values.

## `tahmo_ground_observation`

Catalogue label: **Automated Weather Stations (TAHMO) (QC/QA)  / 2018 - 2025 /  v1**.

| API attribute | Name / meaning | Output unit | Ensemble field |
|---|---|---|---|
| `min_air_temperature` | Air Temperature Min | °C | No |
| `max_air_temperature` | Air Temperature Max | °C | No |
| `average_air_temperature` | Air Temperature Average | °C | No |
| `min_relative_humidity` | Relative Humidity Min | % | No |
| `max_relative_humidity` | Relative Humidity Max | % | No |
| `solar_radiation` | Solar radiation | Wh/m2 | No |
| `precipitation` | Precipitation | mm | No |
| `precipitation_total_era5` | Precipitation Total ERA5 | mm | No |
| `precipitation_total_chirps` | Precipitation Total CHIRPS | mm | No |
| `precipitation_total_qflag` | Precipitation Total Quality Flag | Quality Flag | No |
| `precipitation_total_chirps_qflag` | Precipitation Total CHIRPS Quality Flag | Quality Flag | No |
